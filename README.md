# Inspecteur

Application de bureau pour la gestion des écoles et des enseignants, destinée à faciliter le travail d'un inspecteur de l'éducation.


---

## Présentation

Inspecteur centralise les informations des établissements scolaires et du personnel enseignant dans une seule application, utilisable sans connexion Internet grâce à une base de données locale.

## Fonctionnalités

- Gestion des écoles (ajout, modification, suppression, consultation)
- Gestion des enseignants (informations, affectation à une école)
- Recherche et filtrage des données
- Stockage local des données avec SQLite


## Technologies utilisées

| Partie | Technologies |
|---|---|
| Application de bureau | Electron |
| Interface | React |
| Serveur / logique métier | Node.js |
| Base de données | SQLite |
